## 1. 整理与实现原则

1. 用户可以按任意顺序、使用口语描述想法。
2. 每个可独立实现的功能使用稳定编号：`UMA-001`、`UMA-002`……
3. 用户明确说出的内容记为“已确认需求”；合理但未经确认的补充只能记为“实现建议”或“待确认问题”。
4. 不因后续新想法而静默改写旧决定；发生冲突时记录冲突，并在“决策记录”中说明最终选择。
5. 每个功能必须具有可验证的验收标准，避免只写氛围描述。
6. 实现 AI 应优先复用 CK3 原版机制，并记录参考的原版文件和作用域。
7. 所有脚本、事件、本地化键和资源名称统一使用 `uma_` 前缀，除非本文件另有说明。

## 2. 项目愿景

### 2.1 核心体验

围绕“好看的马娘角色”建立角色收集、遗传与后续马娘骑兵玩法。第一批需求优先解决马娘的身份、外观、生成、寿命、文化与获取方式。

### 2.2 设计边界

- 马娘只有女性。
- MOD 应以最小改动实现，优先新增独立文件，避免覆盖原版内容。
- 所有依赖原版资源或规则的功能都要记录版本更新后的检查位置。

### 2.3 第一版最小可玩范围（MVP）

玩家能够通过决议获得具有马娘特质、马耳、马尾、良好默认外貌和马娘基础文化的女性角色；马娘特质可以遗传，成年后外貌不再衰老，整体平均寿命约为 30—40 岁。

该垂直切片完成后，再按第 5.9 节顺序接入五维与遗传子、培育循环、大赛、军事、建筑和终局内容；P8 的 AI 性能原则从首个阶段起持续适用。

## 4. 系统结构

后续需求按实际内容归入下列模块；没有需求的模块不应自行扩写。

### 4.1 角色与身份

马娘由仅限女性且可以遗传的马娘特质识别。该特质同时是马耳、马尾和其他马娘专属规则的统一判断条件。

### 4.2 获得、培养与成长

玩家主要以训练员身份参与育成。马娘可以通过遗传产生，也可以在启动训练员的决议中招募。6—16 岁为培育阶段，每年增加五项基础数值并随机获得技能。培育可以由马娘教师自动负责；没有教师时，玩家必须选定一名“担当”并亲自培育。担当循环包含训练、外出、休息、夏合训、心动值和干劲。马娘成年后保持成年外貌，平均寿命约为 30—40 岁。

### 4.3 马娘骑兵与军事系统

马娘兵士至少包括基础轻骑兵和重骑兵，初始强度与普通骑兵相近或稍弱。成年马娘可以担任轻骑兵或重骑兵军事顾问，利用自身五项数值为对应兵种提供可在后期达到很高水平的加成。文化传统可以解锁特殊马娘兵士，并通过决议和训练员水平招募。所有马娘都可以担任将领，不受通常的性别要求限制。马娘帝国限制普通骑兵招募，但能廉价招募马娘兵士。

### 4.4 战斗与数值

每名马娘拥有速度、耐力、力量、毅力、智慧五项基础数值。数值不设上限并可随时查看；技能遗传子可能使马娘获得军队指挥官技能或大赛技能。

### 4.5 经济、资源与维护

寻找马娘需要支付金钱。档次越高，成本越高；最高档固定花费 1000 金币。

### 4.6 事件、决议与角色互动

建立整合训练员启动与马娘招募的决议，并允许玩家选择不同价格和品质档次。最高档结果为最高级马娘或“马骨”宝物。另设消耗虔诚的萨满鉴定决议。亲自培育时可以对担当训练、外出或休息，并可举办夏合训与约会活动。玩家还可以举办大型“大赛”活动，邀请训练员携赛马参赛，并进行比赛、报道、胜者舞台、奖励与赌马结算。“马娘文化宣传”活动用于传播训练员身份和提升马娘的智力、外交能力。“马儿跳”作为非性互动保留两个可选分支，怀孕机制仅来自女神赐福。

### 4.7 AI 行为

AI 不运行玩家使用的完整故事循环和逐次交互。所有 AI 培育、训练、关系和年度结算采用简化批量规则，以性能优先，并尽量保持与玩家结果相近的统计分布。AI 只有很小概率主动使用决议成为训练员，但受邀后可以参加大赛。

### 4.8 UI、美术与本地化

马娘必须具有好看的默认外貌，并显示由原版马模型素材改造的马耳和马尾配饰。配饰由马娘特质自动控制。五项基础数值应允许玩家随时查看，遗传子在鉴定前不得显示。训练手册负责展示隐藏较深的规则；大赛需要接近《赛马娘》或真实赛马风格的比赛过程报道。

### 4.9 宫廷职位与职责

- “担当”：没有教师时由玩家亲自培育的一名未成年马娘。
- “教师”：训练宫廷内全部未成年马娘，并每年汇报训练结果。
- “军事顾问”：仅分轻骑兵和重骑兵两类，使用不同基础数值强化对应马娘兵种。
- “种马娘”：在马娘与人类配种时，为人类一方提供遗传子。
- “赛马”：玩家或训练员为当前大赛选定的参赛马娘。

### 4.10 训练员知识与传承

训练员等级可以解锁训练手册和训练书籍。训练手册随机提示不易发现的规则；训练书籍作为宝物为后辈训练员提供加成，尤其提高作者儿子的训练员经验获取，并允许研读训练日记获得一次性训练员经验。

### 4.11 建筑、学院与家族庄园

特雷森学院是参考曼陀罗制寺庙、但功能更接近大学的大型工程或特殊建筑。它强化所有者的训练、马娘数值和马娘兵士，并允许附近角色把担当送来进修。育马者庄园随家族传承，可修建不同建筑，长期强化训练员与马娘相关玩法。

### 4.12 伪成就、血脉与马娘帝国

训练员三条路线全部满级后获得奖励性名声特质、后代降级特质和家族修正。另一条伪成就链允许满足妻子、灵魂伴侣、五维均达到 1200 以上及独立统治者条件的组合拥立“最伟大的马娘”，建立采用游牧制和选举继承的马娘帝国，并形成双方可降级传承的血脉特质。

## 6. 详细实现条目

本节按 P1—P8 实现包排列。条目继续使用稳定 UMA 编号；跨包依赖以 UMA 编号引用。

### 6.1 角色基础、外观与获取（P1）

#### 6.1.1 身份、外观与生命周期（P1.1）

##### UMA-001：女性限定的可遗传马娘特质

- 状态：可实现
- 优先级：MVP
- 已确认需求：马娘身份由专属特质表示；该特质可以遗传；马娘只有女性。
- 规则：男性不能成为马娘；遗传结果只应使女性后代成为马娘。
- 验收标准：
  - [ ] 所有具有马娘特质的角色均为女性。
  - [ ] 马娘能够把特质遗传给女性后代。
  - [ ] 男性后代不会获得马娘特质。
- 待确认问题：马娘特质是否分等级，以及各等级的能力差异。

##### UMA-002：特质关联的马耳与马尾配饰

- 状态：可实现
- 优先级：MVP
- 已确认需求：马娘具有马耳和马尾；素材优先从 P 社原版马模型中提取并以最小改动改造成肖像配饰；配饰必须与马娘特质关联。
- 规则：具有马娘特质时自动显示马耳和马尾；普通角色不得显示。
- 兼容性要求：新增 MOD 自有配饰和肖像规则，不直接修改游戏安装目录中的原版资源。
- 验收标准：
  - [ ] 马耳和马尾在常用肖像场景中位置正确且不明显穿模。
  - [ ] 添加或移除马娘特质后，配饰随之出现或消失。
- 更新检查：原版马模型、肖像配饰定义和肖像修改器规则。

##### UMA-003：好看的默认生成外貌

- 状态：待澄清
- 优先级：MVP
- 已确认需求：由 MOD 生成的马娘默认外貌应当好看。
- 规则：随机生成仍应保留一定差异，不能频繁生成明显不符合预期的脸型。
- 验收标准：
  - [ ] 连续生成一批马娘时，外貌总体符合选定的审美基准且具有差异。
- 待确认问题：审美基准、主要人种外观和是否强制附带原版美貌特质。

##### UMA-004：成年后停止外貌衰老

- 状态：可实现
- 优先级：MVP
- 已确认需求：马娘成年后不再因年龄改变外貌。
- 规则：只固定视觉年龄，不代表马娘不会死亡或拥有无限寿命。
- 验收标准：
  - [ ] 马娘成年后直到死亡都保持成年外貌。
  - [ ] 该规则不使马娘逃避 UMA-005 的寿命机制。
- 更新检查：角色视觉年龄和肖像年龄规则。

##### UMA-005：平均寿命 30—40 岁

- 状态：可实现
- 优先级：MVP
- 已确认需求：马娘群体的平均寿命约为 30—40 岁。
- 规则：这是群体平均目标，不等同于所有马娘在固定年龄强制死亡。
- 验收标准：
  - [ ] 足够样本下，马娘平均死亡年龄落在 30—40 岁范围。
  - [ ] 外貌固定不妨碍寿命结算。
- 待确认问题：是否允许少数马娘明显早亡或活过 40 岁。

##### UMA-006：马娘基础文化

- 状态：待澄清
- 优先级：MVP
- 已确认需求：马娘拥有一种专属基础文化；由 MOD 生成的马娘默认采用该文化。
- 验收标准：
  - [ ] 马娘文化可正常显示名称、语言、服饰和其他文化信息。
  - [ ] “寻找马娘”生成的角色使用该文化。
- 待确认问题：文化名称、传承、语言、武德和初始传统。

#### 6.1.2 寻找马娘与马骨结果（P1.2）

##### UMA-007：分档付费的寻找马娘决议

- 状态：待澄清
- 优先级：MVP
- 已确认需求：玩家可以通过决议“寻找”马娘；选择不同金钱档次会寻找不同档次的马娘。
- 规则：付款档次越高，所得马娘的品质应越高；角色必须满足 UMA-001、UMA-002、UMA-003 和 UMA-006。
- 验收标准：
  - [ ] 决议能展示多个价格档次并正确扣费。
  - [ ] 每个普通档次都能生成对应品质的马娘。
- 待确认问题：普通档次数量、各档价格、品质差异、冷却时间和 AI 是否可以使用。

##### UMA-008：1000 金币最高档与马骨结果

- 状态：待澄清
- 优先级：高
- 已确认需求：最高档固定花费 1000 金币；结果为一名最高级马娘，或者一件“马骨”宝物。
- 验收标准：
  - [ ] 最高档费用始终为 1000 金币。
  - [ ] 执行后只产生最高级马娘或马骨宝物之一。
- 待确认问题：两个结果是随机、由玩家选择还是由条件决定；各自概率；最高级马娘的具体标准；马骨的类型、效果和是否唯一。

### 6.2 五维、遗传子与女神赐福生育（P2）

#### 6.2.1 五维与三类遗传子（P2.1）

##### UMA-009：五项无上限基础数值

- 状态：可实现
- 优先级：MVP
- 已确认需求：每名马娘拥有速度、耐力、力量、毅力、智慧五项基础数值；参考《赛马娘》的数值概念；五项数值均不设上限，并允许玩家随时查看。
- 规则：数值属于每名马娘自身，能够被培育、遗传子和后续系统持续增加。
- 验收标准：
  - [ ] 玩家可以随时查看目标马娘的五项当前数值。
  - [ ] 数值能够持续增长，不受人为硬上限限制。
- 待确认问题：五项数值分别影响哪些大赛、军事或角色效果。

##### UMA-010：1—3 星隐藏遗传子框架

- 状态：待澄清
- 优先级：MVP
- 已确认需求：马娘拥有玩家默认不可见的遗传子；遗传子分为 1 星、2 星、3 星，星级表示效果强弱；遗传子分为能力、技能和大赛三类。
- 规则：未完成 UMA-014 鉴定前，UI 和提示不得泄露具体遗传子；鉴定后允许玩家查看。
- 验收标准：
  - [ ] 系统能为一名马娘保存多种遗传子及其星级。
  - [ ] 未鉴定与已鉴定状态下的信息显示符合规则。
- 规则：遗传子可以按 UMA-015 的规则传给马娘后代，但可能降星或完全不遗传。
- 待确认问题：每名马娘可拥有多少遗传子；是否允许同名遗传子重复。

##### UMA-011：能力遗传子

- 状态：待澄清
- 优先级：高
- 已确认需求：能力遗传子在马娘培育阶段获得并发挥作用；在培育阶段的每一年提供额外基础数值加成；星级决定加成大小。
- 规则：能力遗传子必须指向 UMA-009 的一项或多项基础数值；星级越高，年度加成越大。
- 验收标准：
  - [ ] 培育阶段每年按能力遗传子及星级正确增加基础数值。
- 待确认问题：各星级的年度加成量、一次影响几项数值，以及多个同类遗传子如何叠加。

##### UMA-012：技能遗传子

- 状态：待澄清
- 优先级：高
- 已确认需求：技能遗传子在马娘培育阶段获得并发挥作用；使马娘有概率学会特定技能；技能可以是军队指挥官技能，也可以是大赛技能。
- 规则：每个技能遗传子应指向一个明确技能，并保存 1—3 星星级；星级是否影响学习概率或其他结果尚未确定。
- 验收标准：
  - [ ] 培育阶段能够按技能遗传子尝试授予对应技能。
  - [ ] 军事技能和大赛技能可以分别识别与记录。
- 待确认问题：星级影响触发概率还是技能强度；每年检查还是在特定培育节点检查；失败后能否再次尝试。

##### UMA-013：大赛遗传子

- 状态：待澄清
- 优先级：高
- 已确认需求：马娘通过赢得大赛获得对应的大赛遗传子；大赛遗传子提供特定加成，例如基础数值加成和针对特定大赛的加成。
- 规则：获得条件必须与具体大赛胜利绑定；不同大赛可以产生不同遗传子和效果。
- 验收标准：
  - [ ] 赢得指定大赛后能够获得对应大赛遗传子。
  - [ ] 遗传子能够提供其定义的基础数值或特定大赛加成。
- 规则：大赛遗传子同样分为 1—3 星。
- 待确认问题：星级如何影响加成、能否重复获得，以及加成何时生效。

##### UMA-014：萨满鉴定遗传子决议

- 状态：待澄清
- 优先级：高
- 已确认需求：玩家可以通过一个消耗虔诚的决议寻找萨满，从而得知马娘隐藏的遗传子。
- 规则：鉴定前遗传子不可见；鉴定成功后，玩家能够查看被鉴定马娘的遗传子种类、名称和星级。
- 验收标准：
  - [ ] 决议正确扣除虔诚。
  - [ ] 鉴定完成后仅公开目标马娘实际拥有的遗传子。
- 待确认问题：虔诚花费、选择单个目标还是批量鉴定、鉴定结果是否永久公开、是否需要等待时间或冷却。

#### 6.2.2 继承、配种与种马娘（P2.2）

##### UMA-015：遗传子的继承、降星与丢失

- 状态：待澄清
- 优先级：MVP
- 已确认需求：马娘与人类生下的马娘，有概率继承马娘母亲的遗传子；继承时星级可能降低，也可能完全不遗传。马娘与马娘配种产生的孩子可以从双方继承遗传子，规则相同。
- 规则：每个可继承遗传子分别判定是否遗传及是否降星；结果仍须遵守 1—3 星范围。
- 验收标准：
  - [ ] 马娘与人类产生的马娘后代只从马娘母亲及 UMA-025 指定来源取得遗传子。
  - [ ] 马娘与马娘产生的后代能分别从双方取得遗传子。
  - [ ] 结果能够出现原星级、降低星级和未遗传三种情况。
- 待确认问题：各结果概率、是否可能一次降低多星、1 星降级时如何处理。

##### UMA-016：人工配种系统

- 状态：待澄清
- 优先级：高
- 已确认需求：允许人工安排马娘与其他马娘或人类配种，并为后代结算遗传子。
- 设定规则：配种是非性的配对和女神赐福仪式；后代由赐福产生，因此允许同性组合生育，不依赖现实生殖方式。
- 验收标准：
  - [ ] 玩家能够选择符合条件的配种双方。
  - [ ] 马娘—马娘和马娘—人类两种组合都能产生后代并进入 UMA-015 结算。
- 待确认问题：配种的花费、冷却、年龄与关系限制；女神赐福成功率；后代成为马娘的概率；马娘—马娘组合的亲缘和父母身份如何记录。

##### UMA-025：种马娘宫廷职位

- 状态：待澄清
- 优先级：高
- 已确认需求：建立“种马娘”宫廷职位。当马娘与人类进行女神赐福配种时，种马娘作为人类一方的遗传子来源，供后代按 UMA-015 继承。
- 验收标准：
  - [ ] 马娘—人类配种时能读取当前种马娘的遗传子作为第二来源。
  - [ ] 没有种马娘时，不凭空产生人类一方的遗传子。
- 待确认问题：职位资格、是否全宫廷共用一名种马娘，以及种马娘是否必须参与每次配种。

### 6.3 培育循环与训练员成长（P3）

#### 6.3.1 培育生命周期与宫廷职责（P3.1）

##### UMA-017：6—16 岁培育生命周期

- 状态：待澄清
- 优先级：MVP
- 已确认需求：马娘从 6 岁开始进入培育阶段，到 16 岁成年时结束。培育期间每年增加五项基础数值，并随机获得技能。
- 规则：年度成长须接受能力遗传子、技能遗传子、教师或亲自培育方式的影响。
- 验收标准：
  - [ ] 马娘在 6 岁进入培育，并在 16 岁成年时结束培育。
  - [ ] 培育期每年都会结算五项数值成长和随机技能。
- 待确认问题：年度基础成长量、技能获得概率、结算日期，以及无人培育时是否仍有最低成长。

##### UMA-018：无教师时的亲自培育与担当

- 状态：可实现
- 优先级：高
- 已确认需求：宫廷没有教师时，玩家必须亲自培育马娘；系统开启一个故事循环，并选定一名未成年马娘担任宫廷职位“担当”。
- 规则：亲自培育围绕当前担当展开；更换、成年、离开宫廷或死亡时须结束或转移故事循环。
- 验收标准：
  - [ ] 无教师时能够选定一名符合条件的担当并开启培育故事。
  - [ ] 玩家可以对担当使用 UMA-019 和 UMA-020。
- 待确认问题：同一时间是否只能有一名担当，以及教师就任后现有担当如何处理。

##### UMA-019：担当专项训练交互

- 状态：待澄清
- 优先级：高
- 已确认需求：玩家可以与担当交互，选择速度、耐力、力量、毅力或智慧中的一项作为主要训练方向。交互需要冷却，但应短于此前示例的半年。
- 验收标准：
  - [ ] 玩家可明确选择五项数值之一进行训练。
  - [ ] 训练主要增加所选数值，并受到冷却限制。
- 待确认问题：缩短后的最终冷却、训练量、是否有副属性成长及随机事件。

##### UMA-020：两个月夏合训活动

- 状态：待澄清
- 优先级：高
- 已确认需求：玩家可以为担当开展“夏合训”活动；活动持续两个月，属于集中训练并需要花费金钱。
- 验收标准：
  - [ ] 活动正确持续两个月并扣除费用。
  - [ ] 完成后给予明确的集中训练收益。
- 待确认问题：费用、参加者范围、训练收益、举办频率和风险事件。

##### UMA-021：教师宫廷职位与自动训练

- 状态：待澄清
- 优先级：高
- 已确认需求：成年马娘可以担任教师。教师自动训练宫廷内所有未成年马娘；训练效果取决于教师自身的基础数值、技能和职位称职度。
- 验收标准：
  - [ ] 教师在任时，宫廷内所有培育期马娘都获得自动训练。
  - [ ] 更优秀、更称职的教师能产生更好的平均训练结果。
- 待确认问题：教师的资格要求、称职度公式、哪些数值和技能参与计算。

##### UMA-022：修改训练重心决议

- 状态：待澄清
- 优先级：中
- 已确认需求：玩家可以通过决议修改教师的训练重心。
- 规则：训练重心应对应速度、耐力、力量、毅力或智慧，并影响后续自动训练分配。
- 验收标准：
  - [ ] 决议能够显示并切换当前训练重心。
  - [ ] 新重心影响教师之后的训练结果。
- 待确认问题：是否允许均衡重心、切换成本和冷却。

##### UMA-023：年度训练汇报及关闭选项

- 状态：可实现
- 优先级：中
- 已确认需求：教师每年汇报一次担当或受训马娘的训练结果；玩家可以关闭年度汇报。
- 验收标准：
  - [ ] 开启时每年最多出现一次汇报，并展示训练结果。
  - [ ] 关闭后不再弹出汇报，但训练仍正常进行；玩家可以重新开启。
- 待确认问题：汇报只显示担当还是汇总所有受训马娘。

##### UMA-024：成年后的教师、军事顾问与参赛资格

- 状态：待澄清
- 优先级：高
- 已确认需求：马娘结束培育并成年后，可以担任教师、轻骑兵或重骑兵军事顾问，也可以参加大赛。
- 验收标准：
  - [ ] 未成年马娘不能担任上述成年职位或参加要求成年的大赛。
  - [ ] 成年马娘可以按各系统的资格条件任职和参赛。
- 待确认问题：教师、军事顾问与参赛是否可以同时进行。

#### 6.3.2 训练员身份与三条路线（P3.2）

##### UMA-033：训练员特质与启动决议

- 状态：待澄清
- 优先级：MVP
- 已确认需求：玩家主要以训练员身份参与育成；训练员表现为一个角色特质，并通过与招募马娘整合的决议启动。
- 验收标准：
  - [ ] 决议能够授予训练员特质并进入马娘招募流程。
  - [ ] 已是训练员时不会重复初始化身份。
- 待确认问题：启动费用、资格、是否必须立即招募担当，以及训练员特质是否分等级。

##### UMA-034：三路线训练员成长框架

- 状态：待澄清
- 优先级：MVP
- 已确认需求：训练员分为“教师”“金牌训练员”“爱马者”三条路线；各路线通过不同玩法获得点数并提供不同加成。
- 验收标准：
  - [ ] 三条路线分别记录点数和成长状态。
  - [ ] 各路线只从对应玩法获得点数并提供对应效果。
- 待确认问题：路线是否互斥、点数用途、等级数量和解锁方式。

##### UMA-035：教师训练员路线

- 状态：待澄清
- 优先级：高
- 已确认需求：教师路线为担当提供训练加成；担当完成培育并毕业时，根据担当最终水平给予该路线点数。
- 验收标准：
  - [ ] 路线加成能够改善担当训练结果。
  - [ ] 担当毕业时按其水平结算教师路线点数。
- 待确认问题：担当水平的计算方式、点数公式和具体训练加成。

##### UMA-036：金牌训练员路线

- 状态：待澄清
- 优先级：高
- 已确认需求：金牌训练员路线提供大赛加成；旗下马娘赢得大赛时获得路线点数。
- 验收标准：
  - [ ] 路线加成能够作用于符合条件的大赛。
  - [ ] 马娘获胜后按赛事结果给予路线点数。
- 待确认问题：哪些马娘的胜利计分、不同赛事的点数和具体大赛加成。

##### UMA-037：爱马者训练员路线

- 状态：待澄清
- 优先级：高
- 已确认需求：爱马者通过与马娘外出、约会、配种或发生成年关系获得点数；该路线增加马娘好感度和训练成功率，但会降低人类角色对训练员的好感。
- 验收标准：
  - [ ] 各指定行为能够给予路线点数。
  - [ ] 路线同时产生马娘关系与训练收益，以及人类角色好感惩罚。
- 规则：配种和发生关系只适用于成年角色。
- 待确认问题：各行为点数、好感加成、人类好感惩罚范围，以及“好感度”和 UMA-040 心动值是否为同一数值。

#### 6.3.3 外出、约会、心动、干劲与休息（P3.3）

##### UMA-038：担当外出选项

- 状态：待澄清
- 优先级：高
- 已确认需求：外出是担当培育阶段与训练平级的选项，提供好感度并恢复少量干劲。
- 验收标准：
  - [ ] 玩家可以用一次培育选择执行外出。
  - [ ] 外出增加好感度并少量恢复干劲。
- 待确认问题：外出冷却、好感与干劲数值、事件池和失败可能。

##### UMA-039：约会活动

- 状态：待澄清
- 优先级：中
- 已确认需求：约会表现为活动；对象可以是当前担当、宫廷中的马娘教师或种马娘。
- 规则：未成年担当的约会不直接触发配种或发生关系；关系结果由 UMA-040 在成年时结算。
- 验收标准：
  - [ ] 活动只能选择符合身份与关系条件的目标。
  - [ ] 完成后产生关系收益，并可为爱马者路线提供点数。
- 待确认问题：活动费用、持续时间、冷却、目标年龄和具体事件。

##### UMA-040：心动值与成年关系结算

- 状态：待澄清
- 优先级：高
- 已确认需求：担当故事循环具有心动值。成年结算时，足够高的心动值会触发成为灵魂伴侣或情人的事件；如果在成年前过早达到最高值，会产生不好的结果。
- 验收标准：
  - [ ] 培育过程能够改变并显示心动值。
  - [ ] 成年时按心动值触发相应关系事件。
  - [ ] 成年前达到最高值时触发独立负面结果，而不是提前给予成年关系。
- 待确认问题：数值范围、各结果阈值、灵魂伴侣与情人的选择规则，以及提前满值的负面结果。

##### UMA-041：干劲、年度恢复与训练成功率

- 状态：待澄清
- 优先级：MVP
- 已确认需求：担当故事循环具有干劲数值条。训练消耗干劲；每年结算时恢复一次；当前干劲决定训练成功率。
- 验收标准：
  - [ ] 每次训练正确降低干劲并据此计算成功率。
  - [ ] 年度结算只执行一次规定的干劲恢复。
- 待确认问题：数值范围、训练消耗、年度恢复量和成功率公式。

##### UMA-042：训练失败与不良状态

- 状态：待澄清
- 优先级：高
- 已确认需求：训练可能失败；失败时可能获得不良状态。
- 验收标准：
  - [ ] 训练成功率受干劲及相关加成影响。
  - [ ] 失败能够从定义的状态池中产生相应后果。
- 待确认问题：不良状态列表、概率、持续时间和治疗方式。

##### UMA-043：担当休息选项

- 状态：待澄清
- 优先级：高
- 已确认需求：担当培育阶段可以选择休息；休息随机恢复大、中或小量干劲，同时有小概率获得“睡眠不足”“肥胖”等不良状态。
- 验收标准：
  - [ ] 休息能够按概率产生三档干劲恢复。
  - [ ] 休息存在较低概率产生指定不良状态。
- 待确认问题：各档恢复量和概率、不良状态概率与具体效果。

#### 6.3.4 训练手册、书籍与日记（P3.4）

##### UMA-045：训练手册与随机规则提示

- 状态：待澄清
- 优先级：中
- 已确认需求：训练员达到一定等级后解锁“训练手册”；手册随机展示本 MOD 中不容易发现的规则条目。
- 验收标准：
  - [ ] 未达到要求时不可使用，达到后能够周期性或主动查看随机规则。
  - [ ] 提示只说明规则，不泄露尚未鉴定的角色遗传子等个体隐藏信息。
- 待确认问题：解锁等级、查看方式、提示频率、规则条目池和重复规则。

##### UMA-046：训练书籍宝物与后辈加成

- 状态：待澄清
- 优先级：高
- 已确认需求：训练员达到一定等级后可以生成训练书籍宝物。书籍为后辈训练员提供各种加成，尤其提高作者儿子的训练员经验获取速度。
- 验收标准：
  - [ ] 符合等级要求的训练员能够生成署名书籍宝物。
  - [ ] 合格后辈可以获得书籍加成，作者儿子获得明确的训练员经验加成。
- 待确认问题：生成条件、次数、书籍槽位、继承范围、通用加成和儿子专属加成数值。

##### UMA-047：研读训练日记决议

- 状态：待澄清
- 优先级：中
- 已确认需求：训练书籍可以启用“研读训练日记”决议，一次性给予训练员经验。
- 验收标准：
  - [ ] 只有满足书籍与训练员条件的角色可以研读。
  - [ ] 每次合法研读只结算一次训练员经验。
- 待确认问题：“一次性”按角色、书籍还是决议冷却限制；经验量；书籍是否会消耗。

### 6.4 大赛、演出与奖励（P4）

#### 6.4.1 大赛入口与赛马职位（P4.1）

##### UMA-049：大型“大赛”活动

- 优先级：MVP
- 已确认需求：玩家可以召开大型“大赛”活动，邀请游戏世界中的训练员参加竞技。

  - [ ] 主办者能够选择大赛等级并邀请合格训练员。
  - [ ] 受邀训练员能够携带符合条件的赛马参加。
  - [ ] 活动能够完成比赛、名次、报道、奖励和赌马结算。
- 待确认问题：举办费用、持续时间、地点、冷却、参赛人数和邀请范围。

##### UMA-050：“赛马”宫廷职位

- 状态：待澄清
- 优先级：高
- 已确认需求：最伟大马娘的主头衔采用游牧制，名称变为“马娘帝国”，并采用选举继承法；具有马娘特质的候选人在选举中获得极大加成。
- 验收标准：
  - [ ] 建国后主头衔显示马娘帝国名称并采用指定政体和选举法。
  - [ ] 马娘候选人的选举优势显著，但仍通过选举系统结算。
- 待确认问题：使用哪种游牧政体、选举法、选民范围、马娘加成值和非马娘候选资格。

### 6.8 AI、性能与可选设定互动（P8）

#### 6.8.1 AI 简化与稀有训练员（P8.1）

##### UMA-044：AI 简化培育结算

- 状态：待澄清
- 优先级：MVP
- 已确认需求：AI 使用简化结算以提高性能，不完整运行玩家的训练、外出、休息、约会和故事事件循环。
- 规则：AI 以低频、批量或年度结算方式获得近似成长、关系与状态结果。
- 验收标准：
  - [ ] AI 马娘能够正常成长和毕业，不需要逐次触发玩家事件。
  - [ ] 大量 AI 马娘存在时不会产生明显的高频遍历或事件压力。
- 待确认问题：AI 简化结果与玩家结果允许多大差异。

##### UMA-048：AI 低概率成为训练员

- 状态：待澄清
- 优先级：高
- 已确认需求：AI 只有很小概率主动使用决议成为训练员。
- 验收标准：
  - [ ] AI 训练员在世界中保持稀少，但不会完全消失。
  - [ ] AI 不会高频检查或反复使用启动决议。
- 待确认问题：资格筛选、目标稀有度和检查频率。

#### 6.8.2 可选“马儿跳”互动（P8.2）

##### UMA-062：“马儿跳”囚犯分支

- 状态：待澄清
- 优先级：低
- 实现必要性：可选概念，不要求第一版实现。
- 已确认需求：玩家可以控制一名马娘，并命令她与囚犯进行非性的“马儿跳”互动。互动可能因女神赐福使马娘怀孕，也可能使对象遭受重伤和精神负面状态。
- 设定规则：“马儿跳”不是性交；怀孕不来自参与者之间的性行为，而是女神赐福的超自然结果。
- 验收标准：
  - [ ] 只有满足马娘受控制、对象被囚禁等条件时可用。
  - [ ] 结算能够分别产生女神赐福怀孕、对象重伤和精神负面状态等结果。
- 待确认问题：受控制状态的定义、目标年龄要求、女神赐福概率、伤害与精神状态概率、冷却、观点和暴政后果，以及 AI 是否使用。

##### UMA-063：“马儿跳”儿童分支

- 状态：待澄清
- 优先级：低
- 实现必要性：可选概念，不要求第一版实现。
- 已确认需求：马娘可以与儿童进行同样非性的“马儿跳”互动。儿童分支不会产生女神赐福怀孕、重伤或精神负面状态；儿童反而有概率成为训练员，并获得爱马者路线经验。
- 设定规则：该分支不含性行为，也不产生任何性关系或生育结果。
- 验收标准：
  - [ ] 儿童分支不会触发 UMA-062 的怀孕、重伤和精神负面结果。
  - [ ] 儿童有概率获得训练员身份或资格，并获得爱马者路线经验。
- 待确认问题：目标年龄、训练员转化概率、爱马者经验量、冷却和监护人态度。

## 8. 全局非功能要求

### 8.1 兼容性

- 不无理由覆盖原版文件。
- 优先新增条目或使用脚本化逻辑。
- 必须记录无法避免的兼容性冲突。
- 所有功能优先采用带 `uma_` 前缀的新增文件和对象，不直接改动原版文件。

- 避免无筛选的高频全地图角色遍历。
