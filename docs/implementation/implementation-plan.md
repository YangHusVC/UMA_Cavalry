- 项目：Horse Girls and Cavalry Remake

## 1. 整理与实现原则

1. 用户可以按任意顺序、使用口语描述想法。
2. 每个可独立实现的功能使用稳定编号：`UMA-001`、`UMA-002`……
3. 用户明确说出的内容记为“已确认需求”；合理但未经确认的补充只能记为“实现建议”或“待确认问题”。
4. 不因后续新想法而静默改写旧决定；发生冲突时记录冲突，并在“决策记录”中说明最终选择。
5. 每个功能必须具有可验证的验收标准，避免只写氛围描述。
6. 实现 AI 应优先复用 CK3 原版机制，并记录参考的原版文件和作用域。
7. 所有脚本、事件、本地化键和资源名称统一使用 `uma_` 前缀，除非本文件另有说明。

## 2. 项目愿景

### 2.1 核心体验

围绕“好看的马娘角色”建立角色收集、遗传与后续马娘骑兵玩法。第一批需求优先解决马娘的身份、外观、生成、寿命、文化与获取方式。

### 2.2 设计边界

- 马娘只有女性。
- MOD 应以最小改动实现，优先新增独立文件，避免覆盖原版内容。
- 所有依赖原版资源或规则的功能都要记录版本更新后的检查位置。

### 2.3 第一版最小可玩范围（MVP）

玩家能够通过决议获得具有马娘特质、马耳、马尾、良好默认外貌和马娘基础文化的女性角色；马娘特质可以遗传，成年后外貌不再衰老，整体平均寿命约为 30—40 岁。

## 4. 系统结构

后续需求按实际内容归入下列模块；没有需求的模块不应自行扩写。

### 4.1 角色与身份

马娘由仅限女性且可以遗传的马娘特质识别。该特质同时是马耳、马尾和其他马娘专属规则的统一判断条件。

### 4.2 获得、培养与成长

马娘可以通过遗传产生，也可以由玩家使用分档付费的“寻找马娘”决议获得。马娘成年后保持成年外貌，平均寿命约为 30—40 岁。培育阶段会获得并触发能力遗传子和技能遗传子，影响五项基础数值及技能学习。

### 4.3 马娘骑兵与军事系统

待整理。

### 4.4 战斗与数值

每名马娘拥有速度、耐力、力量、毅力、智慧五项基础数值。数值不设上限并可随时查看；技能遗传子可能使马娘获得军队指挥官技能或大赛技能。

### 4.5 经济、资源与维护

寻找马娘需要支付金钱。档次越高，成本越高；最高档固定花费 1000 金币。

### 4.6 事件、决议与角色互动

建立“寻找马娘”决议，允许玩家选择不同价格和品质档次。最高档结果为最高级马娘或“马骨”宝物。另设消耗虔诚的萨满鉴定决议，用于揭示马娘原本不可见的遗传子。

马娘必须具有好看的默认外貌，并显示由原版马模型素材改造的马耳和马尾配饰。配饰由马娘特质自动控制。五项基础数值应允许玩家随时查看，遗传子在鉴定前不得显示。

## 6. 详细实现条目

### UMA-001：女性限定的可遗传马娘特质

- 状态：可实现
- 优先级：MVP
- 已确认需求：马娘身份由专属特质表示；该特质可以遗传；马娘只有女性。
- 规则：男性不能成为马娘；遗传结果只应使女性后代成为马娘。
- 验收标准：
  - [ ] 所有具有马娘特质的角色均为女性。
  - [ ] 马娘能够把特质遗传给女性后代。
  - [ ] 男性后代不会获得马娘特质。
- 待确认问题：马娘特质是否分等级，以及各等级的能力差异。

### UMA-002：特质关联的马耳与马尾配饰

- 状态：可实现
- 优先级：MVP
- 已确认需求：马娘具有马耳和马尾；素材优先从 P 社原版马模型中提取并以最小改动改造成肖像配饰；配饰必须与马娘特质关联。
- 规则：具有马娘特质时自动显示马耳和马尾；普通角色不得显示。
- 兼容性要求：新增 MOD 自有配饰和肖像规则，不直接修改游戏安装目录中的原版资源。
- 验收标准：
  - [ ] 马耳和马尾在常用肖像场景中位置正确且不明显穿模。
  - [ ] 添加或移除马娘特质后，配饰随之出现或消失。
- 更新检查：原版马模型、肖像配饰定义和肖像修改器规则。

### UMA-003：好看的默认生成外貌

- 状态：待澄清
- 优先级：MVP
- 已确认需求：由 MOD 生成的马娘默认外貌应当好看。
- 规则：随机生成仍应保留一定差异，不能频繁生成明显不符合预期的脸型。
- 验收标准：
  - [ ] 连续生成一批马娘时，外貌总体符合选定的审美基准且具有差异。
- 待确认问题：审美基准、主要人种外观和是否强制附带原版美貌特质。

### UMA-004：成年后停止外貌衰老

- 状态：可实现
- 优先级：MVP
- 已确认需求：马娘成年后不再因年龄改变外貌。
- 规则：只固定视觉年龄，不代表马娘不会死亡或拥有无限寿命。
- 验收标准：
  - [ ] 马娘成年后直到死亡都保持成年外貌。
  - [ ] 该规则不使马娘逃避 UMA-005 的寿命机制。
- 更新检查：角色视觉年龄和肖像年龄规则。

### UMA-005：平均寿命 30—40 岁

- 状态：可实现
- 优先级：MVP
- 已确认需求：马娘群体的平均寿命约为 30—40 岁。
- 规则：这是群体平均目标，不等同于所有马娘在固定年龄强制死亡。
- 验收标准：
  - [ ] 足够样本下，马娘平均死亡年龄落在 30—40 岁范围。
  - [ ] 外貌固定不妨碍寿命结算。
- 待确认问题：是否允许少数马娘明显早亡或活过 40 岁。

### UMA-006：马娘基础文化

- 状态：待澄清
- 优先级：MVP
- 已确认需求：马娘拥有一种专属基础文化；由 MOD 生成的马娘默认采用该文化。
- 验收标准：
  - [ ] 马娘文化可正常显示名称、语言、服饰和其他文化信息。
  - [ ] “寻找马娘”生成的角色使用该文化。
- 待确认问题：文化名称、传承、语言、武德和初始传统。

### UMA-007：分档付费的寻找马娘决议

- 状态：待澄清
- 优先级：MVP
- 已确认需求：玩家可以通过决议“寻找”马娘；选择不同金钱档次会寻找不同档次的马娘。
- 规则：付款档次越高，所得马娘的品质应越高；角色必须满足 UMA-001、UMA-002、UMA-003 和 UMA-006。
- 验收标准：
  - [ ] 决议能展示多个价格档次并正确扣费。
  - [ ] 每个普通档次都能生成对应品质的马娘。
- 待确认问题：普通档次数量、各档价格、品质差异、冷却时间和 AI 是否可以使用。

### UMA-008：1000 金币最高档与马骨结果

- 状态：待澄清
- 优先级：高
- 已确认需求：最高档固定花费 1000 金币；结果为一名最高级马娘，或者一件“马骨”宝物。
- 验收标准：
  - [ ] 最高档费用始终为 1000 金币。
  - [ ] 执行后只产生最高级马娘或马骨宝物之一。
- 待确认问题：两个结果是随机、由玩家选择还是由条件决定；各自概率；最高级马娘的具体标准；马骨的类型、效果和是否唯一。

### UMA-009：五项无上限基础数值

- 状态：可实现
- 优先级：MVP
- 已确认需求：每名马娘拥有速度、耐力、力量、毅力、智慧五项基础数值；参考《赛马娘》的数值概念；五项数值均不设上限，并允许玩家随时查看。
- 规则：数值属于每名马娘自身，能够被培育、遗传子和后续系统持续增加。
- 验收标准：
  - [ ] 玩家可以随时查看目标马娘的五项当前数值。
  - [ ] 数值能够持续增长，不受人为硬上限限制。
- 待确认问题：五项数值分别影响哪些大赛、军事或角色效果。

### UMA-010：1—3 星隐藏遗传子框架

- 状态：待澄清
- 优先级：MVP
- 已确认需求：马娘拥有玩家默认不可见的遗传子；遗传子分为 1 星、2 星、3 星，星级表示效果强弱；遗传子分为能力、技能和大赛三类。
- 规则：未完成 UMA-014 鉴定前，UI 和提示不得泄露具体遗传子；鉴定后允许玩家查看。
- 验收标准：
  - [ ] 系统能为一名马娘保存多种遗传子及其星级。
  - [ ] 未鉴定与已鉴定状态下的信息显示符合规则。
- 待确认问题：遗传子是否以及如何由亲代传给后代；每名马娘可拥有多少遗传子；是否允许同名遗传子重复。

### UMA-011：能力遗传子

- 状态：待澄清
- 优先级：高
- 已确认需求：能力遗传子在马娘培育阶段获得并发挥作用；在培育阶段的每一年提供额外基础数值加成；星级决定加成大小。
- 规则：能力遗传子必须指向 UMA-009 的一项或多项基础数值；星级越高，年度加成越大。
- 验收标准：
  - [ ] 培育阶段每年按能力遗传子及星级正确增加基础数值。
- 待确认问题：各星级的年度加成量、一次影响几项数值，以及多个同类遗传子如何叠加。

### UMA-012：技能遗传子

- 状态：待澄清
- 优先级：高
- 已确认需求：技能遗传子在马娘培育阶段获得并发挥作用；使马娘有概率学会特定技能；技能可以是军队指挥官技能，也可以是大赛技能。
- 规则：每个技能遗传子应指向一个明确技能，并保存 1—3 星星级；星级是否影响学习概率或其他结果尚未确定。
- 验收标准：
  - [ ] 培育阶段能够按技能遗传子尝试授予对应技能。
  - [ ] 军事技能和大赛技能可以分别识别与记录。
- 待确认问题：星级影响触发概率还是技能强度；每年检查还是在特定培育节点检查；失败后能否再次尝试。

### UMA-013：大赛遗传子

- 状态：待澄清
- 优先级：高
- 已确认需求：马娘通过赢得大赛获得对应的大赛遗传子；大赛遗传子提供特定加成，例如基础数值加成和针对特定大赛的加成。
- 规则：获得条件必须与具体大赛胜利绑定；不同大赛可以产生不同遗传子和效果。
- 验收标准：
  - [ ] 赢得指定大赛后能够获得对应大赛遗传子。
  - [ ] 遗传子能够提供其定义的基础数值或特定大赛加成。
- 规则：大赛遗传子同样分为 1—3 星。
- 待确认问题：星级如何影响加成、能否重复获得，以及加成何时生效。

### UMA-014：萨满鉴定遗传子决议

- 状态：待澄清
- 优先级：高
- 已确认需求：玩家可以通过一个消耗虔诚的决议寻找萨满，从而得知马娘隐藏的遗传子。
- 规则：鉴定前遗传子不可见；鉴定成功后，玩家能够查看被鉴定马娘的遗传子种类、名称和星级。
- 验收标准：
  - [ ] 决议正确扣除虔诚。
  - [ ] 鉴定完成后仅公开目标马娘实际拥有的遗传子。
- 待确认问题：虔诚花费、选择单个目标还是批量鉴定、鉴定结果是否永久公开、是否需要等待时间或冷却。

## 7. 数据与命名约定

### 7.1 预期目录

- `common/traits/`：马娘身份或成长相关特质。
- `common/culture/cultures/`：马娘基础文化。
- `common/ethnicities/`：马娘默认生成外貌范围。
- `common/scripted_character_templates/`：不同档次的马娘生成模板。
- `common/artifacts/`：马骨宝物。
- `common/men_at_arms_types/`：马娘骑兵兵种。
- `common/character_interactions/`：角色交互。

## 8. 全局非功能要求

### 8.1 兼容性

- 不无理由覆盖原版文件。
- 优先新增条目或使用脚本化逻辑。
- 必须记录无法避免的兼容性冲突。
- 所有功能优先采用带 `uma_` 前缀的新增文件和对象，不直接改动原版文件。
- 从原版资源改造出的模型必须保留其来源路径，方便游戏更新后比较。

### 8.2 游戏更新检查清单

| 检查对象 | 关联条目 | 原版参考位置 |
|---|---|---|
| 马模型、网格、骨骼与贴图 | UMA-002 | `gfx/models/pets/horses/` |
| 肖像配饰与特质显示规则 | UMA-002、UMA-004 | `gfx/portraits/accessories/`、`gfx/portraits/portrait_modifiers/` |
| 特质遗传与视觉年龄规则 | UMA-001、UMA-004、UMA-005 | `common/traits/` |
| 文化和默认人种生成规则 | UMA-003、UMA-006 | `common/culture/cultures/`、`common/ethnicities/` |
| 决议与角色生成模板 | UMA-007、UMA-008 | `common/decisions/`、`common/scripted_character_templates/` |
| 宝物模板与视觉资源 | UMA-008 | `common/artifacts/` |

游戏大版本更新后，实现 AI 应逐项检查上述参考位置是否改名、删除或改变格式，并在变更记录中写明结果。

### 8.3 性能

- 避免无筛选的高频全地图角色遍历。
- 周期性逻辑必须说明执行频率和候选范围。

### 8.4 可维护性

- 重复条件和效果应提取为 scripted trigger/effect。
- 事件、效果和本地化键须能从前缀与编号追溯到实现条目。
